# Gladio — Brand Brief

## Identity

**Name:** Gladio  
**Origin:** Latin *gladius* — the short Roman sword. Decisive. Sharp. Universally understood.  
**Tagline:** *Veni. Vidi. Vicerunt.* — I came. I saw. They won. (subject shifts: general → athlete)

## Colours

| Token | Hex | Usage |
|-------|-----|-------|
| Black | `#0A0A0A` | Background, primary surfaces |
| Red | `#E8192C` | Live indicators, active scores, CTAs, winner states only |
| White | `#F5F5F5` | Body text, labels |

Red is used with restraint. It signals urgency and live state — never decoration.

## Typography

| Role | Font | Weight |
|------|------|--------|
| Headlines / display | Barlow Condensed | 700–900, uppercase |
| Data / labels / mono | DM Mono | 400 |
| Body | System sans-serif fallback | 300–400 |

## Voice

- Terse. Competitive. Respectful of the sport.
- No exclamation marks in UI copy.
- Numbers and scores are always prominent — the sport is the hero.

## Logo mark

Text-based: `· GLADIO` with a red dot prefix. No icon required at this stage.

## Do / Don't

**Do:** Use red only for live/active states and primary actions.  
**Don't:** Use red for decorative borders, backgrounds, or secondary UI elements.  
**Do:** Keep headlines in uppercase Barlow Condensed.  
**Don't:** Mix font weights casually — weight carries meaning (bold = data point, light = context).
